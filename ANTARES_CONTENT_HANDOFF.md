# ANTARES production content handoff

The website intentionally ships with no fabricated roster, robot specification, outreach statistic or merged team-number history. To convert the current award-oriented framework into a submission-ready team portfolio, provide the following evidence pack.

## 1. Identity — launch blocker

- Confirm the current official FTC team number.
- Explain the relationship between FTC 24924 and FTC 24935 in one short paragraph.
- Confirm whether 24935 achievements may be presented as continuous ANTARES history.
- Provide official team-name spelling and the 2026–27 competition number.
- Provide the current logo as SVG or transparent PNG.

## 2. Current robot — highest visual priority

Preferred source hierarchy:

1. `.step` / `.stp` assembly
2. `.glb` / `.gltf`
3. Fusion 360 / Onshape / SolidWorks source/export
4. orthographic CAD renders if no 3D source can be shared

Also provide:
- robot name;
- drivetrain;
- major mechanisms;
- motors / servos;
- sensors / cameras;
- control hardware;
- dimensions and weight;
- autonomous approach;
- programming language / libraries;
- 3–5 important iterations and what changed.

## 3. Photography

Minimum strong set:
- one clean team portrait;
- individual portraits;
- 5–10 robot detail images;
- workshop / build-process photography;
- pit / field action;
- Indonesia event imagery;
- awards / celebration;
- outreach/community activity.

Use original team-owned files at the highest available resolution. Do not send social-media screenshots when the original image exists.

## 4. Video

Useful clips:
- robot driving;
- intake/scoring mechanism;
- autonomous run;
- close mechanical movement;
- team working in the pit;
- field/match moment;
- event celebration.

4–12 second clean clips are ideal for web loops. Silent source is fine.

## 5. Team

For each current member:
- full name;
- role;
- specialty;
- one concrete contribution;
- portrait;
- publishing consent status.

Provide mentors/coaches separately.

## 6. Outreach / impact

For every metric, provide evidence:
- event name;
- date;
- city;
- audience;
- verified attendee/reach count;
- partner;
- photos/links.

The website will not invent aggregate reach numbers.

## 7. Sponsors

For each current sponsor:
- exact public name;
- SVG/PNG logo;
- website URL;
- current sponsorship status;
- required brand usage rules if any.

## 8. Press

Provide links to:
- ministry/news coverage;
- interviews;
- school publications;
- FIRST event coverage;
- YouTube or broadcast footage.

## Suggested upload structure

```text
ANTARES-PRODUCTION-ASSETS/
  identity/
    logo.svg
    team-number-history.md
  robot/
    robot.step
    robot.glb
    specs.md
    cad-renders/
    photos/
    video/
  team/
    roster.csv
    portraits/
  seasons/
    2023-centerstage/
    2024-into-the-deep/
    2025-decode/
    2026-biobuzz/
  outreach/
  sponsors/
  press/
```

The biggest quality jump will come from the real robot model and original photography. The current branch already reserves the visual and interaction space needed for both.
