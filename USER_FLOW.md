# Portfolio user flow

```text
Arrival
  -> identify Daniyal and his operating thesis
  -> enter selected work
  -> choose a flagship chapter
       -> JARVIS: inspect public architecture/source
       -> HELIX: run the explicit interaction proof
       -> QADAM: inspect benchmark methodology/source
  -> understand operating method and capabilities
  -> browse the active field of public builds
  -> understand THINK / BUILD / PROVE operator profile
  -> open private project brief
       -> validate fields
       -> submit to private inbox
       -> receive atomic success or recovery message
  -> return to top or leave through truthful repository links
```

Persistent desktop wayfinding and the contained mobile menu provide direct routes to Work, Method, About, and Contact. Reduced-motion, save-data, and no-JavaScript sessions preserve the same semantic order, links, form fields, and final states; only progressive media and smooth/scrubbed motion are removed.
