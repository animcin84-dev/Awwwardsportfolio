# UI Inspiration Capture: Spatial Portfolio Systems

Date: 2026-08-26

The recurring pattern is disciplined contrast: one dominant visual system, type that changes scale and anchor between chapters, sparse controls, and concrete work destinations. The useful lesson is not to add more effects. It is to make each motion event change the visitor's understanding of the work.

## Why these prompts work

Each long prompt in `manifest.json` names a visual mechanism, the content hierarchy it must protect, motion timing, responsive behavior, accessibility requirements, and the reference traits that must not be copied. That keeps inspiration concrete without turning any source into a template.
