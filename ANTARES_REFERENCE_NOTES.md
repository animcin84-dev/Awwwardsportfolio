# ANTARES reference and originality notes

The ANTARES branch was developed from the existing Awwwardsportfolio architecture plus a user-supplied reference pack. The reference projects are treated as technique study material, not as a source of brand assets or page-level cloning.

## User-supplied source categories

- Codrops cinematic scroll / sticky-grid / Three.js gallery demos — scroll choreography, progressive reveal and DOM/WebGL synchronization principles.
- BraveBot website — robotics information architecture and the interaction principle of selecting a robot subsystem to inspect explanatory data.
- React Three Fiber, Drei and gltfjsx — the production 3D stack and future CAD-to-web pipeline.
- Shader repositories, OGL and ShaderGradient — procedural rendering and shader-study references.
- Showcase Images / Curtains.js — gallery and DOM/WebGL image-treatment references.
- Motion Primitives, React Bits, Magic UI, Cult UI, AnimBits, GSAP UI, Aetheris UI — microinteraction and component-pattern references.

- The WebGL red-supergiant sphere in `app/components/AntaresStarCanvas.tsx`, including its GLSL noise/fbm implementation and R3F scene composition.
- The Almaty → Depok mission chapter and event-data presentation.

## Assets policy

No demo robot, template photograph, third-party brand artwork or AI-fabricated robot is presented as ANTARES evidence. The robot explorer remains a deliberately abstract placeholder until the team supplies its own CAD/GLB/STEP source and media.

Demo/repository licenses and individual asset licenses must be checked again before any third-party code or asset is copied into production. The current ANTARES implementation intentionally favors original implementation over wholesale code transfer.
